# Capture Flow

1. Validate the URL and require legal permission.
2. Reject phishing-sensitive targets by default.
3. Fetch public HTML, metadata, styles, assets, fonts, and screenshots.
4. Analyze typography, colors, spacing, layout, forms, buttons, animations, responsive behavior, icons, images, SEO, and Open Graph metadata.
5. If Cloudflare, CAPTCHA, bot verification, human verification, login, or paywall protection appears, pause capture.
6. Show an embedded browser session. The user manually verifies or logs in.
7. Resume only after successful manual verification.
8. Log manual verification. Stop with a clear error if verification fails.
9. Generate frontend code and optional backend plan.
10. Apply prompt corrections, commit changes, and deploy when credentials are configured.
