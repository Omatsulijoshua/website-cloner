# Safety And Abuse Prevention

CloneForge AI is designed for authorized recreation only.

- Users must check a legal permission box before any clone job starts.
- Bank, government, crypto exchange, webmail, social media login, and phishing-sensitive domains are blocked by default.
- The crawler does not bypass paywalls, CAPTCHA, Cloudflare, human verification, or login systems.
- When bot protection appears, capture is paused and the user must complete verification manually in an embedded browser session.
- The system logs that manual verification was required and stops if verification fails.
- Login-assisted capture never stores passwords and treats browser session data as encrypted, short-lived data.
- Private messages, financial data, passwords, and personal user data are out of scope and must not be captured.
